## Zeiten

| Tiempo | Forma |
|---|---|
| Präteritum | er g**i**ng |
| Perfekt | er **ist** gegangen |
| Konjunktiv II | er ginge |

## Imperativ

| | |
|---|---|
| du | Geh! |
| ihr | Geht! |
| Sie | Gehen Sie! |

## Regiert

| Construcción | Para qué | Ejemplo |
|---|---|---|
| `gehen zu` + Dativ | a casa de alguien, a un sitio concreto | *Ich gehe zum Arzt.* |
| `gehen in` + Akk | entrar en | *Ich gehe in die Küche.* |
| `gehen nach` + nombre de lugar | ciudades y países sin artículo | *Ich gehe nach Berlin.* |
| `es geht` | impersonal | *Wie geht's? Es geht.* |

## Notiz

**Perfekt con `sein`**, como todos los verbos de movimiento: *ich **bin** gegangen*.

**`zu`, `in` o `nach`** es el error clásico. `nach` para ciudades y países sin artículo, `zu` para personas y sitios concretos, `in` + acusativo cuando entras dentro de algo.

*Mein Fehler vom 2026-08-01:* el orden era *ich bin **zum Bahnhof** gegangen*, con el participio al final.
