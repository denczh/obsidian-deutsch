| Perfekt | er hat aufbewahrt |
| Konjunktiv II | - |

## Imperativ

| | |
|---|---|
| du | Bewahr(e) ... auf! |
| ihr | Bewahrt ... auf! |
| Sie | Bewahren Sie ... auf! |

## Regiert

| Construcción | Para qué | Ejemplo |
|---|---|---|
| `etwas in` + Dativ `aufbewahren` | dónde lo guardas | *Ich bewahre die Bettlaken im Schrank auf.* |

## Notiz

**Separable, pero el participio no lleva `ge-`.** Es *hat **aufbewahrt***, no *aufgebewahrt*: el verbo base es `bewahren`, con prefijo inseparable `be-`, y ese `be-` bloquea el `ge-` aunque el `auf-` se separe. Es la excepción más fácil de fallar de esta lista.

En la frase, `auf` se va al final: *ich bewahre alles im Schrank **auf***.
