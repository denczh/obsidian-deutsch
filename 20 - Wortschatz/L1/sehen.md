## Präsens

| | |
|---|---|
| ich | sehe |
| du | s**ie**hst |
| er/sie/es | s**ie**ht |
| wir | sehen |
| ihr | seht |
| sie/Sie | sehen |

## Zeiten

| Tiempo | Forma |
|---|---|
| Präteritum | er sah |
| Perfekt | er hat gesehen |
| Konjunktiv II | er sähe |

## Imperativ

| | |
|---|---|
| du | S**ie**h! |
| ihr | Seht! |
| Sie | Sehen Sie! |

## Regiert

| Construcción | Para qué | Ejemplo |
|---|---|---|
| `etwas sehen` + Akk | qué ves | *Ich sehe die Lampe.* |
| `sehen aus` | tener aspecto, separable | *Das Zimmer sieht gut aus.* |

## Notiz

Cambio vocálico `e` → `ie` en la 2ª y 3ª del singular: *du s**ie**hst*, *er s**ie**ht*. En el imperativo de tú también: *sieh!*

**Frente a [[schauen]]:** `sehen` es percibir con los ojos, sin intención; [[schauen]] es dirigir la mirada. Para *ver la tele* se usa `fernsehen`.
