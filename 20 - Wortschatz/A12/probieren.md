**probieren** · *verb* · *probiert, probierte, hat probiert*. Auxiliar `haben`, regelmäßig.

## Beispiel

- **DE:** Tobias probiert ein kleines Stück.
- **ES:** Tobias prueba un trozo pequeño.

## Präsens

| | |
|---|---|
| ich | probiere |
| du | probierst |
| er/sie/es | probiert |
| wir | probieren |
| ihr | probiert |
| sie/Sie | probieren |

## Imperativ

| | |
|---|---|

## Regiert

| Construcción | Para qué | Ejemplo |
|---|---|---|
| **`probieren` + Akkusativ** | probar algo | *Ich probiere den Kuchen.* |

## Notiz

**Los verbos en `-ieren` no llevan `ge-` en el participio:** *hat probiert*, nunca *hat geprobiert*. Lo mismo vale para [[programmieren]].
